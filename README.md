One original dad joke, one line: **I told the broccoli to stop stalking me — it said it was just branching out.**

The setup uses "stalking" in its everyday sense; the reply flips it to the
plant's stalk, then lands the second turn with "branching out". One pun,
resolved in the last two words, easy to say out loud at the dinner table.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the joke (76 characters, 78 bytes, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, inside the gate of 1–140 characters.
